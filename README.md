# Volt-Charge — EV Subscription Landing Page

A modern SaaS landing page for a fictional electric vehicle subscription service, built from scratch with HTML, CSS and JavaScript.

## Features
- Fully responsive on all screen sizes
- Fluid typography and spacing using clamp() and CSS variables
- Hero section with radial glow effect
- Feature cards with hover animations
- 3-step how it works section
- Testimonials with avatar initials
- 3-tier pricing section with featured card highlight
- CTA banner with glow overlay
- Smooth footer layout

## Tech Stack
HTML · CSS · JavaScript · Font Awesome Icons

## Design
Original design concept inspired by modern SaaS landing pages. Built entirely from scratch without a Figma reference.
